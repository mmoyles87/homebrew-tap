# homebrew-tap

Homebrew formulae by Matt Moyles.

```sh
brew install mmoyles87/tap/ans2irc
brew install mmoyles87/tap/jotmail
brew install mmoyles87/tap/jotdo
```

| Formula | |
|---|---|
| [ans2irc](https://github.com/mmoyles87/ans2irc) | Convert ANSI art to mIRC-coloured text that fits in IRC messages |
| [jotmail](https://github.com/mmoyles87/jotmail) | Notes from your IMAP mailbox (Apple Notes, Fastmail), in a terminal |
| [jotdo](https://github.com/mmoyles87/jotdo) | Reminders from your CalDAV server (Nextcloud, Apple Reminders), in a terminal |
